# 마케터: 카피와 소재 대량 생산 (터미널 에이전트 실전)

이 문서는 Threads 연재 4편의 상세 근거 자료입니다. 코딩을 모르는 마케터가 터미널 에이전트(Claude Code, Codex)에게 실제로 시켜 볼 수 있는 지시문을 그대로 담았습니다.

## 왜 앱이 아니라 터미널 에이전트인가

카피 문구 하나를 뽑는 일은 앱으로도 됩니다. 하지만 마케터의 실제 하루는 "문구 하나"가 아니라 "채널 3개 × 길이 3벌 × 소재 여러 장 × 링크 수십 개"입니다.
터미널 에이전트는 내 컴퓨터의 **카피 파일, 이미지 폴더, 성과 데이터 CSV를 직접 열어서, 여러 벌을 한꺼번에 만들어 파일로 저장합니다.** 하나씩 복사해 붙여넣는 반복 노동이 사라집니다.

- 앱: "카피 한 벌을 보여 주는 도구"
- 터미널 에이전트: "내 폴더에 여러 벌·여러 규격을 실제로 만들어 두는 도구"

## 준비: 작업 폴더에 자료를 모아 둔다

바탕화면에 `마케팅2026` 폴더를 만들고 그 안에 이렇게 넣어 둡니다.

- `브랜드가이드.md` (우리 브랜드 말투, 써도 되는 말·쓰면 안 되는 말)
- `이미지/` 폴더 (원본 이미지들)
- `성과데이터.csv` (지난 게시물의 문구·노출·클릭·전환 같은 숫자)

터미널에서 이 폴더로 이동한 뒤 에이전트를 실행하면, 지시문에서 파일 이름만 말해도 에이전트가 찾아 읽습니다.

> 참고: 이미지 규격 변환은 에이전트가 컴퓨터에 설치된 이미지 변환 도구(예: ImageMagick)를 이용해 처리합니다. 없으면 에이전트가 설치를 안내하거나 대신 설치해 줍니다. 처음 한 번만 준비하면 됩니다.

## 작업 1. 채널별 길이 맞춤 카피 여러 벌 한 번에 만들기

인스타, 스레드, 블로그는 어울리는 길이와 말투가 다릅니다. 같은 메시지를 채널별로 다시 쓰는 일을 한 번에 시킵니다.

### 복붙용 지시문 예시

```
브랜드가이드.md 를 먼저 읽고 우리 말투와 금지 표현을 지켜 줘.
아래 핵심 메시지를 세 채널용 카피로 각각 3벌씩 만들어 줘.

핵심 메시지: "[여기에 이번에 알리려는 내용 한두 줄]"

채널별 규칙:
- 인스타그램: 2~3줄, 캐주얼한 말투, 마지막에 어울리는 해시태그 5개.
- 스레드: 280자 이내, 대화하듯 자연스럽게, 해시태그 없이.
- 블로그 도입부: 3~4문장, 검색을 고려한 제목 후보 3개 포함.

결과는 "카피_초안.md" 파일에 채널별로 제목을 나눠 정리해 줘.
과장 표현("최고", "무조건", "1위")과 브랜드가이드 금지어는 쓰지 마.
각 카피 아래에 몇 자인지 글자 수를 표시해 줘.
```

### 결과가 어떻게 나오나

- `카피_초안.md` 한 파일에 채널별로 3벌씩, 총 9벌이 정리됩니다.
- 각 카피 밑에 글자 수가 표시되어, 채널 규격에 맞는지 바로 확인됩니다.
- 브랜드가이드를 먼저 읽혔기 때문에 말투가 우리 것에 가깝게 나옵니다.

### 주의점

- **브랜드가이드를 먼저 읽으라고 지시하는 것이 핵심입니다.** 이 한 줄이 없으면 밋밋하고 우리답지 않은 카피가 나옵니다.
- 카피는 초안입니다. 그대로 게시하지 말고, 사실과 다른 내용·과장은 사람이 걸러 내세요. 특히 가격·성능·"1위" 같은 주장은 근거가 없으면 삭제합니다.
- 카피를 만든 도구가 자기 카피를 스스로 "좋다"고 평가하게 두지 마세요. 고를 때는 사람의 눈으로 판단합니다.

## 작업 2. 이미지 규격 일괄 변환하기

같은 소재를 인스타 정사각형, 스토리 세로, 썸네일 등 여러 규격으로 만들어야 할 때가 많습니다. 폴더 안 이미지를 한꺼번에 변환하게 시킵니다.

### 복붙용 지시문 예시

```
이미지 폴더 안에 있는 모든 jpg와 png 파일을 아래 세 규격으로 변환해 줘.
원본은 그대로 두고, 규격별 폴더를 새로 만들어서 그 안에 저장해 줘.

- 인스타_정사각형: 1080 x 1080
- 스토리_세로: 1080 x 1920
- 썸네일: 600 x 600

- 비율이 안 맞으면 잘라내지 말고, 남는 부분은 흰색 배경으로 채워 줘.
- 파일 이름은 원본 이름을 유지해 줘.
- 몇 개 파일을 각각 몇 개 규격으로 변환했는지 마지막에 요약해 줘.
```

### 결과가 어떻게 나오나

- `인스타_정사각형/`, `스토리_세로/`, `썸네일/` 폴더가 새로 생기고, 각 폴더에 변환된 이미지가 들어갑니다. 원본은 그대로 남습니다.
- "원본 20장 → 각 3규격, 총 60장 생성" 처럼 요약이 나옵니다.

### 주의점

- **자르기(crop) 방식을 분명히 지시하세요.** "잘라내지 말고 흰 배경으로 채워"인지, "가운데 기준으로 잘라"인지에 따라 결과가 완전히 달라집니다.
- 변환 결과는 눈으로 몇 장 열어 확인하세요. 로고나 글자가 잘리지 않았는지 사람이 보는 것이 안전합니다.
- 이미지 변환 도구(ImageMagick 등)가 없으면 에이전트가 먼저 설치를 진행합니다. 회사 컴퓨터라면 설치 권한을 미리 확인하세요.

## 작업 3. UTM 링크 대량 생성하기

캠페인 성과를 채널별로 추적하려면 링크마다 UTM 꼬리표를 붙여야 합니다. UTM은 링크 끝에 붙는 표식으로, "이 클릭이 어느 채널·어느 게시물에서 왔는지" 분석 도구가 알아보게 해 줍니다. 이걸 손으로 만들면 오타가 나기 쉽습니다.

### 복붙용 지시문 예시

```
아래 기본 링크에 UTM 꼬리표를 붙여서, 채널별 추적 링크를 한꺼번에 만들어 줘.

기본 링크: https://우리사이트.com/이벤트
캠페인 이름(utm_campaign): autumn_sale_2026

채널(utm_source / utm_medium)은 아래 조합으로 만들어 줘.
- instagram / social
- threads / social
- blog / referral
- newsletter / email

각 링크에 대해 "채널 이름 | 완성된 링크" 형태로 표를 만들고,
"utm_링크.csv" 파일로 저장해 줘. 엑셀에서 바로 열 수 있게.
띄어쓰기나 대문자 없이 소문자로 통일하고, 오타 없이 정확히 만들어 줘.
```

### 결과가 어떻게 나오나

- `utm_링크.csv` 파일이 생기고, 엑셀에서 열면 채널별 완성 링크가 표로 정리되어 있습니다.
- 각 링크는 `...?utm_source=instagram&utm_medium=social&utm_campaign=autumn_sale_2026` 형태로 규칙에 맞게 만들어집니다.

### 주의점

- **캠페인 이름과 채널 표기를 미리 통일하세요.** `Instagram`과 `instagram`이 섞이면 분석 도구가 다른 채널로 셉니다. 소문자·언더바로 통일하라고 지시하는 것이 좋습니다.
- 만든 링크는 실제로 하나 눌러서 페이지가 열리는지 확인하세요. 기본 링크에 오타가 있으면 전부 깨집니다.
- 이 작업은 외부에 무언가를 보내지 않고 링크만 만드는 것이라 위험이 낮습니다. 부담 없이 시험해 보기 좋은 작업입니다.

## 작업 4. 과거 성과 데이터(CSV)에서 잘된 카피 패턴 뽑기

지난 게시물의 숫자에는 "무엇이 통했는지"가 들어 있습니다. 성과 CSV를 읽혀서 잘된 카피의 공통점을 정리하게 시킵니다.

### 준비

- `성과데이터.csv`에 최소한 이런 칸이 있으면 좋습니다: 게시일, 채널, 카피 문구, 노출 수, 클릭 수, 전환 수.

### 복붙용 지시문 예시

```
성과데이터.csv 를 읽어 줘. 각 게시물의 클릭률(클릭 수 ÷ 노출 수)을 계산해서,
클릭률이 높은 상위 10개와 낮은 하위 10개를 나눠 줘.

그다음 상위 카피들의 공통점을 찾아서 정리해 줘.
- 어떤 표현·문장 구조·길이·단어가 자주 나오는지,
- 하위 카피와 무엇이 다른지,
- 다음에 쓸 카피에 적용할 규칙 3~5개.

계산 결과와 분석을 "성과_카피분석.md" 로 저장하고,
상위 10개 목록도 표로 같이 넣어 줘.
숫자는 데이터에 있는 것만 쓰고, 없는 값은 지어내지 마.
```

### 결과가 어떻게 나오나

- `성과_카피분석.md` 파일에 상위/하위 목록과 함께, "질문형 첫 문장이 평균 클릭률이 높다", "20자 이내 짧은 카피가 더 잘 눌렸다" 같은 패턴 정리가 담깁니다.
- 다음 카피에 바로 적용할 규칙 몇 가지가 문장으로 나옵니다.

### 주의점

- **성과 데이터는 늦게 오고 흔들립니다(노이즈).** 게시물 몇 개의 우연한 결과일 수 있으므로, 나온 패턴은 "확정된 법칙"이 아니라 "다음에 시험해 볼 가설"로 받아들이세요.
- 클릭률이 높아도 전환이 낮으면 좋은 카피가 아닐 수 있습니다. 클릭만이 아니라 전환까지 같이 보라고 지시에 넣으면 더 정확합니다.
- 숫자는 데이터에 있는 것만 쓰라고 못 박으세요. 근거 없는 수치를 지어내면 잘못된 방향으로 캠페인이 갈 수 있습니다.

---

## 이 편의 핵심 한 줄

터미널 에이전트는 "카피 한 벌을 보여 주는 도구"가 아니라, **내 브랜드가이드·이미지 폴더·성과 CSV를 직접 읽어서 여러 벌 카피·여러 규격 이미지·추적 링크·성과 분석을 파일로 만들어 두는 도구**입니다. 만들어진 것은 모두 초안이고, 게시하는 결정은 언제나 사람이 합니다.
