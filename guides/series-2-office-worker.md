# 2편 — 사무직 파일 정리 자동화

> 이 글은 Threads 연재 '코딩 없이 터미널 에이전트 활용하기'의 2편 상세 근거 자료입니다.
> 1편(설치하고 첫 명령 내리기)에서 이어집니다.

사무직이 매주 반복하는 손 아픈 일들이 있습니다. 폴더에 쌓인 파일 이름 통일, 날짜별 분류, 엑셀 여러 개 합치기, 회의록에서 할 일 추리기. 사람이 하면 한 시간씩 걸리는 일을 터미널 에이전트는 몇 분 만에, 그것도 **실제 파일로** 처리합니다. 챗봇이 "이렇게 하세요"라고 설명하는 것과 달리, 에이전트는 **직접 해서 결과를 남깁니다.**

이 편의 지시문은 그대로 복사해서 쓸 수 있게 만들었습니다. `Claude Code`든 `Codex`든 작업할 폴더에서 실행한 뒤 붙여넣으면 됩니다.

> **시작 전 공통 수칙 (매 작업 필수)**
> 1. **원본 백업**: 작업할 폴더를 통째로 복사해 `_백업`을 붙여 두세요. 잘못돼도 되돌릴 수 있습니다.
> 2. **계획 먼저**: 모든 지시문에 "먼저 어떻게 할지 보여주고, 내가 확인하면 실행해"를 넣으세요.
> 3. **결과 확인**: 다 끝나면 폴더를 열어 몇 개만 눈으로 검수하세요.

---

## 작업 1. 파일 이름 규칙 통일하기

**상황**: '계약서' 폴더에 `계약서final.pdf`, `계약서_최종(2).pdf`, `abc계약 진짜최종.pdf` 처럼 제각각인 파일이 수백 개.

**복붙용 지시문**
```
이 '계약서' 폴더의 PDF 파일들을 살펴봐. 파일 이름이 제각각이라
'2026-08-29_거래처명_계약서' 형식(날짜_거래처_문서종류)으로 통일하고 싶어.
파일 안 내용을 참고해서 거래처명과 날짜를 알아내줘.
먼저 '기존 이름 → 바꿀 이름' 대조표를 보여주고,
내가 좋다고 하면 그때 실제로 이름을 바꿔줘. 원본 폴더는 미리 백업해뒀어.
```

**결과가 어떻게 나오나**
- 에이전트가 먼저 이런 대조표를 보여줍니다:
  ```
  계약서final.pdf        → 2026-07-10_한빛상사_계약서.pdf
  계약서_최종(2).pdf     → 2026-08-01_대성물산_계약서.pdf
  abc계약 진짜최종.pdf   → 2026-08-22_ABC유통_계약서.pdf
  ```
- 확인하고 "진행해"라고 하면 실제 파일 이름이 전부 바뀝니다.

**주의점**
- PDF 안에 날짜·거래처가 안 적혀 있으면 에이전트가 못 찾습니다. 이럴 땐 "날짜를 모르는 건 `날짜미상`으로 표시해"라고 덧붙이세요.
- 이름을 바꾸는 작업이므로 **반드시 백업 먼저**. 대조표 단계에서 이상하면 그냥 중단하면 됩니다.

## 작업 2. 날짜별 폴더로 분류하기

**상황**: '다운로드' 폴더에 몇 달 치 파일이 뒤섞여 수백 개. 월별로 정리하고 싶음.

**복붙용 지시문**
```
이 폴더의 파일들을 만든 날짜(또는 파일명에 있는 날짜) 기준으로
'2026-06', '2026-07', '2026-08'처럼 '연-월' 폴더를 만들어서 그 안으로 옮겨줘.
먼저 '어떤 파일이 어느 폴더로 갈지' 목록으로 보여주고,
확인받으면 실제로 옮겨줘. 옮기다 이름이 겹치면 뒤에 번호를 붙여줘.
```

**결과가 어떻게 나오나**
- `2026-06` / `2026-07` / `2026-08` 폴더가 생기고, 파일들이 해당 폴더로 이동합니다.
- 이동 전에 "이 파일 47개는 2026-08로, 30개는 2026-07로…" 하고 미리 알려 줍니다.

**주의점**
- '만든 날짜'와 '파일 이름 속 날짜'가 다를 수 있습니다. 어느 기준을 쓸지 지시문에 명확히 적으세요("파일명에 날짜가 있으면 그걸 우선").
- 파일을 **옮기는** 작업이라 백업이 특히 중요합니다.

---

## 작업 3. 엑셀·CSV 여러 개를 하나로 병합하기

**상황**: 지점별 매출 엑셀 12개가 따로따로. 하나로 합쳐서 봐야 함.

**복붙용 지시문**
```
이 폴더에 지점별 매출 엑셀 파일이 여러 개 있어. 열 구성(날짜, 지점, 품목, 금액)은 모두 같아.
이걸 하나의 엑셀로 합쳐줘. 어느 파일에서 온 행인지 알 수 있게
'출처파일'이라는 열을 맨 앞에 추가해줘.
결과는 '전체매출_병합.xlsx'로 저장하고, 원본 파일들은 건드리지 마.
합친 뒤 총 몇 행이 됐는지, 파일별로 몇 행씩 들어갔는지 알려줘.
```

**결과가 어떻게 나오나**
- `전체매출_병합.xlsx`라는 파일이 새로 생깁니다. 12개 파일 내용이 한 시트에 쌓이고, 맨 앞에 '출처파일' 열이 붙습니다.
- "총 3,480행. 강남점 290행, 부산점 310행…" 식으로 검산용 요약을 줍니다. 이 숫자로 빠진 파일이 없는지 바로 확인할 수 있습니다.

**주의점**
- 파일마다 열 이름·순서가 다르면 엉킬 수 있습니다. "열 이름이 다르면 합치지 말고 어떤 파일이 다른지 알려줘"를 붙이면 안전합니다.
- 원본은 읽기만 하고 **새 파일로만 저장**하므로 이 작업은 비교적 안전합니다. 그래도 결과 파일의 행 수는 꼭 검산하세요.

## 작업 4. 회의록에서 '할 일'만 뽑아 목록화하기

**상황**: 두서없이 받아 적은 회의록 텍스트에서 실제 실행할 일(액션 아이템)만 추려야 함.

**복붙용 지시문**
```
이 폴더의 '0829_주간회의.txt'를 읽고, 앞으로 누가 무엇을 언제까지 해야 하는지
'할 일'만 뽑아줘. 각 항목은 '담당자 / 할 일 / 기한' 형식으로 정리하고,
기한이 안 나온 건 '기한 미정'으로 표시해줘.
결과는 '0829_할일목록.txt'로 저장하고, 단순 논의·잡담은 빼줘.
```

**결과가 어떻게 나오나**
- `0829_할일목록.txt`가 새로 생기고 이런 식으로 정리됩니다:
  ```
  - 김대리 / 제안서 초안 작성 / 9월 3일까지
  - 박과장 / 거래처 견적 재확인 / 기한 미정
  - 이팀장 / 예산안 승인 요청 / 이번 주 금요일
  ```
- 원본 회의록은 그대로 두고, 실행 목록만 별도 파일로 남습니다.

**주의점**
- 회의록이 애매하게 적혀 있으면 담당자·기한을 놓칠 수 있습니다. 뽑힌 목록은 한 번 훑어보고 빠진 걸 보완하세요.
- 여러 회의록을 한꺼번에 처리하고 싶으면 "이 폴더의 회의록 파일 전부에 대해 똑같이 해서 각각 `_할일목록`으로 저장해"라고 하면 됩니다.

## 한 단계 더 — 반복 작업 묶기

위 작업들이 익숙해지면 여러 개를 한 번에 시킬 수도 있습니다.
```
이 폴더를 정리해줘. 순서는 이래:
1) 파일 이름을 '날짜_거래처_문서종류'로 통일
2) 그다음 '연-월' 폴더로 분류
각 단계마다 계획을 먼저 보여주고, 내가 확인하면 다음으로 넘어가.
```
에이전트가 단계별로 진행하며 매번 확인을 받습니다. 사람이 한 시간 걸릴 일이 몇 분으로 줄어듭니다.

## 마무리

핵심은 하나입니다. 챗봇은 **'방법'을 알려주고**, 터미널 에이전트는 **폴더 안 파일을 실제로 정리해 결과물을 남깁니다.** 반복되는 파일 잡무일수록 효과가 큽니다.

**안전하게 쓰는 3원칙**을 다시 강조합니다: **① 원본 백업 → ② 계획 먼저 확인 → ③ 결과 검수.** 이 세 개만 지키면 실수해도 되돌릴 수 있습니다.

**다음 편(3편)**에서는 영업 직군 — **고객 목록 정리, 팔로업 대상 추리기, 회사별 맞춤 제안서 만들기** — 를 다룹니다.
