# 1편 — 설치하고 첫 명령 내리기

> 이 글은 Threads 연재 '코딩 없이 터미널 에이전트 활용하기'의 1편 상세 근거 자료입니다.
> 0편(왜 터미널 에이전트인가)에서 이어집니다.

## 이 편에서 다루는 것

- 터미널 에이전트가 뭔지 (Claude Code / Codex)

## 1. 터미널 에이전트가 뭔가요

**Claude Code**(앤트로픽)와 **Codex**(오픈AI)는 '터미널'이라는 검은 화면에서 돌아가는 AI 비서입니다. 겉모습은 낯설지만, 하는 일은 단순합니다. **내 컴퓨터의 폴더와 파일을 직접 읽고, 고치고, 새로 만들어 줍니다.**

챗봇 앱과의 결정적 차이가 여기 있습니다.

| | ChatGPT·Claude 앱 | 터미널 에이전트 (Claude Code·Codex) |
|---|---|---|
| 하는 일 | 질문에 **답을 알려줌** | 내 컴퓨터에서 **결과물을 만들어 냄** |
| 파일 접근 | 내가 하나씩 올려야 함 | 폴더 전체를 직접 열어봄 |
| 결과 | 화면에 글로 보여줌 | 실제 파일이 정리·생성됨 |
| 예시 | "엑셀 병합하는 법 알려줘" | "이 폴더 엑셀 5개를 하나로 합쳐줘" → 합친 파일이 생김 |

즉 앱은 **'방법을 설명하는 도구'**, 터미널 에이전트는 **'대신 해주고 결과를 남기는 도구'**입니다. 코딩을 몰라도 됩니다. 사람 말로 시키면 됩니다.

> **어느 걸 써야 하나요?** 둘 다 기능이 비슷합니다. Claude 구독(Pro/Max 등)이 있으면 Claude Code, ChatGPT 구독이 있으면 Codex를 쓰면 됩니다. 이 글은 두 개를 나란히 안내하니 가진 쪽으로 따라 하세요.

## 2. 설치 — 큰 흐름만

설치는 명령어 한 줄을 복사해서 터미널에 붙여넣는 게 전부입니다. 세부 사항은 계속 바뀌므로 **아래 공식 문서 링크를 최종 기준**으로 삼으세요. 여기서는 '어떤 순서로 흘러가는지'만 잡아 드립니다.

### 터미널 여는 법

- **맥**: 스팟라이트(⌘+스페이스)에서 `터미널` 또는 `Terminal` 검색 → 실행
- **윈도우**: 시작 메뉴에서 `PowerShell` 검색 → 실행

검은(또는 파란) 화면에 커서가 깜빡이면 준비 완료입니다.

### Claude Code 설치

- **맥 / 리눅스**: 터미널에 아래 한 줄을 붙여넣고 엔터
  ```
  curl -fsSL https://claude.ai/install.sh | bash
  ```
- **윈도우 (PowerShell)**:
  ```
  irm https://claude.ai/install.ps1 | iex
  ```
- 설치가 끝나면 확인:
  ```
  claude --version
  ```
  버전 숫자와 `(Claude Code)`가 뜨면 성공입니다.
- 작업할 폴더에서 `claude` 라고 치면 대화가 시작됩니다. 처음 실행하면 **Claude 계정 로그인** 안내가 나옵니다(Pro·Max 등 구독 필요).
- 공식 설치 문서: https://code.claude.com/docs/en/quickstart

### Codex 설치

- **맥 / 리눅스**:
  ```
  curl -fsSL https://chatgpt.com/codex/install.sh | sh
  ```
- **윈도우 (PowerShell)**:
  ```
  powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
  ```
- 작업할 폴더에서 `codex` 라고 치면 시작됩니다. 처음엔 **ChatGPT 계정으로 로그인**을 고르면 됩니다.
- 공식 설치 문서: https://learn.chatgpt.com/docs/codex/cli

> **막히면?** 설치 중 빨간 에러가 나면, 그 에러 문구를 그대로 복사해 챗봇에 붙여넣고 "이거 어떻게 해결해?"라고 물어보세요. 대부분 5분 안에 풀립니다. 공식 문제해결 문서도 링크로 연결돼 있습니다.

## 3. 첫 명령 — '무엇을 / 언제 / 어떤 형식으로'

에이전트를 실행하면 그냥 사람에게 부탁하듯 한글로 쓰면 됩니다. 다만 세 가지를 챙기면 결과가 확 좋아집니다.

- **무엇을**: 정확히 어떤 작업인지 (막연한 '정리해줘' 말고 '무엇을 어떻게 정리')
- **언제 / 어떤 범위**: 어느 폴더·어느 파일 대상인지
- **어떤 형식으로**: 결과를 어떤 모양으로 받고 싶은지 (파일? 목록? 표?)

### 시작할 때 딱 좋은 첫 명령

에이전트를 켜자마자 아래처럼 물어보세요. 뭔가를 바꾸기 전에 '이 폴더에 뭐가 있는지 파악부터' 시키는 안전한 첫걸음입니다.

```
지금 이 폴더에 어떤 파일들이 있는지 살펴보고, 종류별로 몇 개씩 있는지 간단히 표로 알려줘. 아직 아무것도 바꾸지 마.
```

결과: 에이전트가 폴더를 훑어보고 "PDF 12개, 엑셀 5개, 이미지 30개…" 식으로 정리해 보여줍니다. 파일은 하나도 건드리지 않습니다.

## 4. 좋은 지시문 vs 나쁜 지시문

같은 일을 시켜도 문장에 따라 결과가 달라집니다.

**나쁜 예 ❌**
```
파일 좀 정리해줘
```
왜 나쁜가: 무엇을·어느 폴더·어떤 기준으로 정리할지 하나도 없음. 에이전트가 제멋대로 판단해 엉뚱하게 건드릴 수 있음.

**좋은 예 ✅**
```
바탕화면의 '영수증' 폴더 안 파일들을 살펴봐. 파일 이름을
'2026-08-15_스타벅스_4500원' 형식(날짜_상호_금액)으로 바꾸고 싶어.
먼저 어떻게 바꿀지 목록으로 보여주고, 내가 확인하면 그때 실제로 바꿔줘.
```
왜 좋은가: 대상 폴더·원하는 형식·**실행 전 확인 단계**까지 다 들어 있음.

핵심 원칙 세 가지:

1. **대상을 콕 집는다** — "그 폴더" 말고 "바탕화면의 영수증 폴더".
2. **원하는 결과 모양을 보여준다** — 예시 이름·표·목록 형태를 직접 써 준다.
3. **'먼저 계획부터 보여주고 확인받아라'를 붙인다** — 실수를 미리 막는 안전장치.

## 5. 첫날 해볼 만한 안전한 작업 3개

원본을 망가뜨릴 위험이 낮고, 결과가 눈에 확 들어오는 것부터 시작하세요.

### ① 폴더 내용 파악하기 (읽기만, 100% 안전)
```
이 폴더에 있는 파일들을 종류와 개수로 정리해서 표로 보여줘.
파일은 절대 바꾸지 말고 보기만 해.
```
결과: 폴더 현황 표. 아무것도 변하지 않음.

### ② 긴 문서 요약해서 새 파일로 저장하기
```
이 폴더의 '보고서.txt'를 읽고 핵심 3줄 요약을 만들어서
'보고서_요약.txt'라는 새 파일로 저장해줘. 원본은 그대로 둬.
```
결과: 원본은 그대로 있고, 요약본 파일이 하나 새로 생김. 원본을 안 건드리니 안전.

### ③ 오늘 할 일 목록 파일 만들기
```
'오늘_할일.txt' 파일을 만들고, 아래 내용을 체크박스 목록으로 정리해서 넣어줘:
은행 서류 제출, 3시 회의 준비, 저녁 장보기, 부모님 전화.
```
결과: 깔끔한 체크리스트 파일이 새로 생성됨.

> **첫날 안전 수칙**
> - **새로 만들거나 읽기만** 하는 작업부터 시작하세요. '기존 파일을 바꾸는' 작업은 익숙해진 뒤에.
> - 중요한 폴더는 **미리 복사본을 하나 떠두세요**. (폴더 통째로 복사 → 이름에 `_백업` 붙이기)
> - 에이전트가 "이렇게 바꿀게요"라고 계획을 보여주면, **눈으로 확인한 뒤 진행**시키세요.

## 마무리

터미널 에이전트는 '답을 아는 비서'가 아니라 '**대신 손을 움직여 결과물을 만드는 비서**'입니다. 첫날은 읽기·새로 만들기 위주로 감을 잡으면 충분합니다.

**다음 편(2편)**에서는 사무직이 가장 자주 겪는 일 — **폴더에 쌓인 수백 개 파일 정리, 엑셀 여러 개 병합, 회의록에서 할 일만 뽑아내기** — 를 실제 복붙용 지시문과 함께 다룹니다.
