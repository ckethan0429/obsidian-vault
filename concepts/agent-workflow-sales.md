# 에이전트 위임을 위한 영업 업무 프로세스

[[agent-workflow-governance]]의 상태 전이·증거·승인 골격을 고티켓 B2B 영업에 적용한다. 원본 실무는 아웃리치 문안과 대면 클로징 가이드다. 영업자도 혼자 메시지를 보내는 사람이 아니라 자격·진단·결재·세금계산서를 통과하는 파이프라인을 가진 사람이다.

> 에이전트에게 메시지를 맡기는 것이 아니라, 검증 가능하고 되돌릴 수 있는 영업 프로세스를 맡긴다.

기존 이론 페이지는 [[b2b-sales-and-negotiation-strategy]], [[sales-discovery-and-objection-handling]], [[proposal-and-closing-strategy]]다. 이 문서는 그 이론을 게이트가 있는 실행 사이클로 고정한다.

## 개발·마케팅과의 대응

| 개발자 | 마케터 | 영업 |
|---|---|---|
| 온보딩 문서 | 브랜드 가이드 | ICP, 금지 사항, 상품·가격, 갱신 트리거 |
| 서브브랜치 | 캠페인 ID | 리드 ID + 채널(소개/인바운드/자격통화) |
| 관련 코드 탐색 | 기존 에셋 | 지인·트리거·과거 대화·증거 자산 |
| 커밋 | 초안 체크포인트 | 문안 초안 → 자격 메모 → 진단 제안 |
| 로컬 테스트 | 프리뷰·클레임 검사 | 스팸/과장/무료진단/회사명 검사 |
| PR | 스테이징 리뷰 | 발송 전 독립 리뷰 |
| CI | 트래킹·예산 검사 | 자격 기준, 가격 규칙, 세금계산서 선결 |
| CD | 채널 게시·지출 | 사람 발송, 미팅, 유료 진단, 본계약 |
| 관찰 | CTR/CPA | 회신, 착석, 진단 성사, 품의 진행 |

핵심 차이: 마케팅 CD는 채널 게시이고, 영업 CD는 **상대의 시간·돈·결재**를 움직인다. 콜드 대량 발송은 개발의 테스트 우회와 같다.

## 영업 사이클

### 0. 업무 접수
- 목표(진단/본계약), 대상 유형, 채널, 이번 달 수용량(1~2건)을 고정한다.
- 산출물: 오퍼 정의, 금지 목록, 롤백(정정·철회) 조건.
- 게이트: 사업자등록·세금계산서가 없으면 본계약 트랙을 시작하지 않는다.

### 1. 영업 온보딩
- ICP, 주력 오퍼, 가격 규칙, 증거 자산, 금지 표현을 읽는다.
- 금지: 스팸, 콜드 대량, 회사명 노출, 고객 실명, 무료 상세 진단, 레인지 가격.
- 게이트: 문서 규칙과 실제 발송 권한이 일치하는지 확인한다.

### 2. 리드 분해와 트랙 분기
- A 소개 요청 / B 담당자 직접 / 인바운드 / 대면. LinkedIn 1:다는 오디언스가 있을 때만.
- 리드 ID를 만든다. 예: `lead/vmware-renewal-warm-2026-08`.
- 게이트: 구현 전에 채널과 오퍼(이관·챗봇·GPU·모니터링)를 검토한다.

### 3. 관련 접점 탐색
- 전 직장·업계 지인, 갱신 트리거, 기존 대화, 블로그·자가진단 자산을 찾는다.
- 산출물: 대상 2~3명, 소개 경로, 증거 링크.
- 게이트: 이미 거절·무응답인 대상을 재촉하지 않는다.

### 4. 단계별 산출과 체크포인트
~~~text
1. 가설과 대상
2. 문안 초안
3. give(자가진단) 링크
4. 자격 질문
5. 유료 진단 제안(50만, 차감)
6. 미팅/팔로업 메모
~~~
각 단계는 되돌릴 수 있는 초안이어야 한다. 한 번에 본계약을 닫으려 하지 않는다.

### 5. 로컬 검증
- 스팸성, 과장, 무료 처방, 회사명, 고객 실명, 레인지 가격, 거짓 희소성.
- 게이트: “괜찮아 보인다”가 아니라 금지 목록 체크와 문안 diff를 검토한다.

### 6. 리뷰 요청
- 목적, 대상, 채널, 오퍼, 검증 결과, 실패 시 내리는 방법을 적는다.
- 발송 주체는 사람이다. 에이전트는 초안과 검사만 한다.

### 7. 영업 CI
- 자격 기준(규모·예산대·시점·결재권자 접근)
- 무료 범위 준수(15분 감별 + 자가진단만)
- 고정가/3옵션, 진단비 차감 조항
- 세금계산서 가능 여부
- 게이트: 필수 검사를 통과해야 한다. 우회는 별도 승인이다.

### 8. 독립 리뷰
~~~text
Copy Agent A     → 문안·대본 초안
Reviewer B       → Enns/Dunford/Stark 렌즈(무료진단·마감·차별점)
Legal/Claims C   → 과장, 실명, 회사명, 증거 범위
Analyst D        → 오퍼·가격·수용량이 가설과 맞는지
Human            → 외부 발송과 가격 승인
~~~
문안을 만든 모델이 자기 문안을 평가하면 안 된다.

### 9. 소프트 런치
- A(소개 요청) 2~3명, 또는 자격 통화 1건부터.
- 게이트: 승인한 문안과 실제 발송본이 같고, give 링크가 동작한다.
- “초안 완료”와 “상대에게 도달”을 별도로 증명한다.

### 10. 본 집행
| 위험도 | 예시 | 게이트 |
|---|---|---|
| 낮음 | 문안 초안, 자료 검색 | 자동 검사 |
| 보통 | 지인 소개 요청 | 독립 리뷰 + 사람 발송 |
| 높음 | 담당자 직접, 자격 통화 | 사람 승인 |
| 치명적 | 유료 진단 제안, 본계약, 세금계산서 | 사람 승인 + 선결 조건 |

롤백은 메시지 삭제/정정, 제안 철회, 다음 단계 중단이다. 나간 신뢰는 코드처럼 되돌리기 어렵다.

### 11. 집행 후 관찰
- 회신, 착석, 진단 성사, 품의 진행, 무응답.
- 무응답은 1회만 자연 후속. 재촉 금지가 회로 차단기다.
- 미팅 후 24시간 안에 챔피언 무장 자료를 보낸다.

### 12. 학습
- 이긴/진 문장, 반론, 자격 탈락 이유를 자산화한다.
- 반복 실패를 다음 CI 규칙으로 승격한다. 예: 무료 진단 문장 자동 거부.

## 하드 게이트

1. 콜드 대량 발송 금지. 아는 사람, 구체적으로, 한 번만.
2. 무료는 감별까지. 상세 진단·품의 문서는 유료 50만, 이관 계약 시 전액 차감.
3. 가격은 레인지가 아니라 고정가 또는 3옵션.
4. 회사명 미표기. 고객사 실명·서버 정보 금지.
5. 담당자 ≠ 결재권자. 그 자리 계약 강요 금지. 목표는 챔피언 무장.
6. 세금계산서 없으면 거래 성립 안 함.
